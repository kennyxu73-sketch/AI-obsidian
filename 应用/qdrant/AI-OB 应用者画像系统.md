



# AI-OB 应用者画像系统（Phase 2 · Qdrant）

## 一、定位

AI-OB 在二期引入 Qdrant 后，从：

- 记录工具（记录回忆）
- 辅助工具（提供建议）

升级为：

> **认知增强系统（Cognitive Augmentation System）**

其核心能力是：

> 不仅“记住你”，更“理解你”，并持续“补全你”。

---

## 二、核心意义

### 1. 从“记忆存储” → “人格建模”

传统 RAG：
- 解决：信息检索

AI-OB（二期）：
- 解决：认知建模 + 决策辅助

实现：

```text
数据 → 记忆 → 认知 → 人格 → 决策能力
````

---

### 2. 从“用户辅助” → “用户补全”

  

AI-OB 不仅回答问题，还要：

- 发现你没说的
    
- 指出你忽略的
    
- 补齐你缺失的结构
    

---

### 3. 从“工具” → “长期协同体”

  

系统目标：

  

> 构建一个“越来越懂你”的 AI 内阁系统

  

具备：

- 长期记忆
    
- 决策风格理解
    
- 认知偏好建模
    
- 动态进化能力
    

---

## 三、系统结构（基于 Qdrant）

  

### 整体架构

```
用户输入 / 行为 / 回忆
        ↓
小忆（结构化 + 潜台词识别）
        ↓
Embedding（语义向量化）
        ↓
Qdrant（长期记忆库）
        ↓
记忆检索（多维过滤）
        ↓
人格建模（Persona Engine）
        ↓
认知补全（Gap Detection）
        ↓
LLM 输出（个性化 + 进化型回答）
```

---

## 四、核心模块设计

  

### 1. 记忆层（Memory Layer）

  

#### 功能

- 存储所有用户相关信息
    

  

#### 数据结构（Qdrant Payload）

```
{
  "type": "认知/决策/情绪/事实",
  "summary": "...",
  "content": "...",
  "agent": "小忆",
  "project": "AI-OB",
  "timestamp": "2026-03-18",
  "emotion": "neutral",
  "importance": "high",
  "tags": ["本地优先", "数据主权"]
}
```

---

### 2. 人格层（Persona Layer）

  

#### 目标

从记忆中提炼：

- 偏好（Preferences）
    
- 信念（Beliefs）
    
- 决策模式（Decision Patterns）
    
- 盲点（Blind Spots）
    

---

#### 示例

```
Kenny_Persona:

preferences:
  - 本地部署优先
  - 系统化解决方案

beliefs:
  - 数据主权高于便利性
  - AI 应具备长期记忆能力

decision_patterns:
  - 优先考虑长期价值
  - 避免平台依赖

blind_spots:
  - 易陷入技术细节
```

---

### 3. 认知补全层（Cognitive Augmentation Layer）

  

这是系统最核心的能力。

---

#### 作用

当用户提出想法时，小忆需要：

  

##### 1. 识别缺口（Gap Detection）

检查是否缺少：

- 技术可行性
    
- 商业模式
    
- 用户场景
    
- 系统扩展性
    

---

##### 2. 提供补全（Completion）

例如：

```
用户：我想做一个 AI 养老系统

小忆：
已识别结构：
- 产品方向：养老
- 技术方向：AI

可能缺失：
- 商业模式
- 目标用户细分
- 数据来源

建议：
是否先定义 MVP？
```

---

##### 3. 指出偏差（Deviation Detection）

```
检测到：
当前方案依赖云服务

与你的长期偏好（本地优先）冲突
```

---

##### 4. 提供进化路径（Evolution Suggestion）

```
建议路径：

Phase1：本地 MVP
Phase2：引入向量数据库
Phase3：构建 Memory OS
```

---

### 4. 检索层（Qdrant Retrieval Layer）

  

#### 检索维度

- 语义相似（embedding）
    
- 时间（最近/历史）
    
- 类型（认知/决策）
    
- Agent 来源
    
- 重要性
    

---

#### 检索组合

```
最终上下文 =

语义相关记忆
+ 最近记忆
+ 人格模型
```

---

## 五、小忆的工作流程（核心 SOP）

  

### Step 1：输入解析

- 提取显性内容
    
- 识别潜台词
    
- 判断任务类型
    

---

### Step 2：记忆写入

- 结构化为记忆单元
    
- 生成 embedding
    
- 写入 Qdrant
    

---

### Step 3：人格更新

  

条件：

```
重要性 = 高
且 类型 = 认知 / 决策
```

→ 更新 Persona

---

### Step 4：检索与分析

- 调用 Qdrant
    
- 获取相关记忆
    
- 加载 Persona
    

---

### Step 5：认知补全

  

执行：

- 缺口检测
    
- 风险识别
    
- 结构补全
    

---

### Step 6：输出生成

  

生成：

- 个性化回答
    
- 结构化建议
    
- 下一步行动
    

---

## 六、系统进化机制

定期执行：

输出：

```
- 新增偏好

```
