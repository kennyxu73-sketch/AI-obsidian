重点包括：

- 单模结构
    
- 数据隔离
    
- 工作流程
    
- 安全规则
    
- 输出规范

## 一、系统目标

  

小报系统的目标是：

```
对外部信息进行自动搜索、整理与分析，
生成可供决策参考的情报简报，
并在经过人工审核后进入本地知识体系。
```

核心原则：

1. 外部搜索能力
    
2. 数据主权保护
    
3. AI辅助研究
    
4. Human-in-the-Loop
    

---

# 二、系统架构原则

  

小报系统采用 单模架构（Single-Mode Intelligence Agent）。

  

系统只存在一个核心研究 Agent，但其运行环境必须与本地知识系统进行 数据隔离。

  

系统结构：

```
外部信息
   ↓
小报 Agent（DMZ隔离区）
   ↓
数据净化
   ↓
研究生成
   ↓
人工审核
   ↓
AI-OB知识库
```

---

# 三、网络与数据隔离规则

  

为了保护 AI-OB 的本地知识体系，小报系统必须遵守以下隔离原则。

  

## 1 外部访问权限

  

小报 Agent 允许访问互联网资源：

  

允许：

- 搜索引擎
    
- 新闻网站
    
- GitHub
    
- 公开论文
    
- 技术社区
    

  

禁止：

- 访问本地知识库
    
- 读取 AI-OB Vault
    
- 访问内部数据库
    

---

## 2 本地知识保护

  

AI-OB 本地知识系统必须遵守：

```
AI-OB 不直接联网
```

所有外部数据进入本地系统必须经过：

```
数据净化层
```

---

## 3 DMZ 隔离区

  

小报 Agent 必须运行在 隔离执行环境（DMZ） 中。

  

DMZ 的特点：

```
允许访问互联网
禁止访问内部知识库
只允许文本数据向内流动
```

DMZ 与 AI-OB 之间只允许：

```
结构化文本数据
```

禁止：

- HTML
    
- 脚本
    
- 二进制文件
    

---

# 四、信息处理流程

  

小报系统的工作流程如下。

  

## 1 信息输入

  

输入来源包括：

- RSS
    
- 搜索关键词
    
- 手动提交链接
    
- AI监控主题
    

  

输入统一称为：

```
Signal（信号）
```

---

## 2 信息搜索

  

小报 Agent 执行外部搜索任务：

  

可能使用：

- 搜索 API
    
- 网页抓取工具
    
- RSS 聚合
    

  

输出：

```
Raw Content（原始内容）
```

---

## 3 数据净化

  

所有 Raw Content 必须经过 净化处理。

  

净化规则包括：

1. 去除 HTML 标签
    
2. 去除脚本代码
    
3. 去除广告内容
    
4. 统一编码格式
    
5. 删除追踪参数
    

  

输出：

```
Clean Text（净化文本）
```

---

## 4 AI研究生成

  

Research Agent 对 Clean Text 进行分析。

  

研究任务包括：

- 信息摘要
    
- 背景分析
    
- 技术判断
    
- 趋势判断
    

  

生成：

```
小报草稿
```

---

# 五、小报内容结构

  

每条小报建议使用固定结构。

  

标准结构：

```
标题

来源
（原始链接）

事件摘要
（发生了什么）

背景信息
（为什么重要）

影响分析
（可能带来什么变化）

建议关注点
（未来观察方向）
```

---

# 六、人工审核机制

  

小报草稿必须经过人工审核。

  

审核角色：

```
Human-in-the-Loop
```

审核内容包括：

- 信息真实性
    
- 分析合理性
    
- 是否存在误导
    
- 是否具有战略价值
    

  

审核结果分为：

|等级|处理方式|
|---|---|
|A级|进入战略知识库|
|B级|进入参考知识库|
|C级|存档|
|D级|丢弃|

---

# 七、知识库写入规则

  

只有经过审核的内容才能进入 AI-OB。

  

写入结构：

```
AI-OB
 ├ Strategy（战略）
 ├ Knowledge（参考）
 └ Archive（存档）
```

原则：

```
原始数据不直接进入知识库
```

必须是：

```
结构化研究结果
```

---

# 八、安全规则

  

小报系统必须防范以下风险：

  

### 1 Prompt Injection

  

网页内容不得直接进入 Agent prompt。

  

必须：

```
先净化再分析
```

---

### 2 数据泄露

  

外部模型不得获得：

- 本地知识
    
- 内部文件
    
- 私有数据
    

---

### 3 恶意网页

  

禁止处理：

- 含脚本执行页面
    
- 未知下载文件
    
- 可执行代码
    

---

# 九、系统日志

  

系统必须记录：

```
搜索记录

```

所有日志统一进入：

```
Audit Log
```
