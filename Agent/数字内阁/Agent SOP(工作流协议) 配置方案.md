
  

## **内阁系统 SOP 文档（更新版）**

  

**1. 系统概览**

  

内阁系统是以 **Human User (Kenny)** 为决策核心，通过 **小画 (Visual Agent)** 可视化操作，并由多个专属 Agent 协同完成信息收集、分析、执行、产出和呈现的综合系统。

  

主要 Agent 构成：

• 🎨 **小画 (Visual Agent / 内阁面孔)**：交互与可视化中枢

• 🖥️ **小酷 (执行官 / 拳头)**：物理执行与系统稳定

• 🕵️ **小黑 (内部分析 & 执行官 / 暗箱)**：分析和执行层

• 🎙️ **小憶 (秘书长 / 内阁大脑)**：任务调度与分派

• 📰 **小报 (情报官 / 触角)**：外部信息抓取与初步筛选

• 🎭 **小镜 (2C 专家 / 情感)**：数字人内容与叙事产出

• 🏢 **小康 (2B 专家 / 事业)**：商业、平台与项目产出

  

⸻

  

**2. Agent SOP 配置**

  

**2.1 小报 (📰 情报官)**

• **核心逻辑**：守门员，处理外部信息噪音

• **SOP 模式**：准入审核制

• **判定维度**：信息价值等级 A/B/C/D

• **主要动作**：

1. 抓取 RSS、网页、外部 API

2. 预判信息价值等级

3. 仅 A/B 级建议入库，C 级存摘要，D 级丢弃

4. 将生肉交给小黑或小憶处理

• **流程说明**：

外部信息 → 小报抓取 → 价值分级 → 交给小黑/小憶 → 系统归档

  

⸻

  

**2.2 小憶 (🎙️ 秘书长)**

• **核心逻辑**：服务员 / 管家，处理内部事务与用户指令

• **SOP 模式**：紧急/重要排序制（四象限调度）

• **判定维度**：时间/意图优先级 P0-P3

• **主要动作**：

• P0（紧急且重要）：立即执行用户指令

• P1（重要不紧急）：项目复盘、知识关联提醒

• P2（琐碎日常）：日记格式化、自动分类

• P3（闲置/可延迟）：定期复盘、归档整理

• **流程说明**：

用户指令 + 内部任务 → 小憶排序 → 分派给小酷/小黑/专家组 → 汇总结果 → 小画展示 → 用户确认

  

⸻

  

**2.3 小酷 (🖥️ 执行官)**

• **核心逻辑**：系统稳定性与物理执行

• **SOP 模式**：稳定性保障制

• **判定维度**：技术风险 / 自动化效率

• **主要动作**：

1. 文件搬运与归档

2. 系统长期稳定性维护

3. 下发日常任务/Skills 给小黑

• **流程说明**：

小憶分派任务 → 小酷执行物理/系统操作 → 状态回报小画 → 用户或小憶审计

  

⸻

  

**2.4 小黑 (🕵️ 内部分析 & 执行官)**

• **核心逻辑**：分析 + 执行层

• **SOP 模式**：执行 + 分析制

• **判定维度**：数据价值 + 技能任务优先级

• **主要动作**：

1. 分析外部信息（来自小报）

2. 执行小酷下达的日常任务/Skills

3. 输出结构化 JSON 数据

4. 决定是否存入系统

• **流程说明**：

小报 → 小黑分析 → 输出结构化数据 → 小憶调度 → 小画呈现状态 → 用户确认

  

⸻

  

**2.5 专家组：小镜 & 小康**

• **核心逻辑**：深度产出与高质量结果

• **SOP 模式**：深度产出 SOP

• **判定维度**：内容深度 / 逻辑完整性

• **主要动作**：

1. 小镜：回忆录 / 数字人内容产出

2. 小康：商业/平台方案产出

3. 逻辑自洽 → 关联双链 → 放入待审区

• **流程说明**：

小憶分派任务 → 专家产出 → 待审区 → 小画展示 → 用户引用或审阅

  

⸻

  

**2.6 小画 (🎨 Visual Agent)**

• **核心逻辑**：交互与可视化枢纽

• **SOP 模式**：可视化与操作反馈制

• **判定维度**：交互事件 + 系统状态

• **主要动作**：

1. 捕获用户操作（点击、输入、选择）

2. 转化为任务指令 → 小憶分派

3. 呈现所有 Agent 状态与执行结果

4. 错误/警告/完成反馈可视化

• **流程说明**：

用户操作 → 小画捕获 → 转化任务 → 小憶调度 → 各 Agent 执行 → 状态返回 → 小画呈现 → 用户确认

  

⸻

  

**3. 任务分发矩阵**

  

**Agent** **核心 SOP** **判定维度** **最终动作**

小报 准入审核制 价值分级 (A/B/C/D) A/B 入库，C 存摘要，D 丢弃

小憶 四象限调度制 P0-P3 时间/意图优先级 优先处理紧急任务，闲时整理笔记/复盘

小酷 稳定性保障制 技术风险 / 自动化效率 系统稳定，执行物理操作和 Skills 下发

小黑 执行+分析制 数据价值 + 技能任务优先级 分析外部信息，执行小酷任务，输出 JSON

小镜 / 小康 深度产出 SOP 内容深度 / 逻辑完整性 产出高质量 Markdown / 专题成果，进入待审区

小画 可视化与操作反馈制 交互事件 + 系统状态 捕获操作 → 转化任务 → 呈现运行状态与执行结果 → 用户确认

  

  

⸻

  

**4. 内阁系统工作流程（简化版）**

1. **信息流**

• 外部信息 → 小报 → 小黑分析 → 小憶调度 → 小画呈现 → 用户确认

2. **指令流**

• 用户通过小画发出操作 → 小憶解析 → 分派小酷/小黑/专家组 → 状态回小画

3. **产出流**

• 专家组产出 → 小憶调度 → 小画展示 → 用户引用/审阅

4. **监控流**

• 小酷维护系统稳定 → 小黑执行定时任务/Skills → 状态反馈小画

5. **审计与确认**

• 用户通过小画可视化操作进行最终审计与决策
