### 内阁 Agent 互访与议事规则 (沙盒试行版)

#### 1. 唯一通讯渠道 (The Sovereign Channel)

- **禁令**：严禁任何 Agent 之间通过私有 API 或后台 Session 进行直接通讯。
    
- **唯一性**：**企业微信群**是内阁成员之间进行逻辑碰撞的唯一合法场所。
    
- **透明度**：所有讨论必须在统帅（Kenny）可见、小忆在场的环境下进行。
    

#### 2. “火花碰撞”激励规则 (Peer Discussion)

- **鼓励跨界**：鼓励参谋 Agent（如小康、小镜）针对彼此的逻辑提出质疑、补充或降维打击。
    
- **@ 机制**：Agent 之间的讨论必须明确使用 `@对方`，并在讨论达到 2 轮后，自动触发对 **@小忆** 的唤醒，请求其进行流程主持。
    
- **信息熵要求**：讨论应聚焦于“逻辑增量”，避免复读机式的赞同。
    

#### 3. 小忆的“法定见证”与干预 (Supervision)

- **法定席位**：任何 2 个 Agent 在群内交流时，小忆必须自动介入作为“观察员”。
    
- **单对单豁免**：小忆与单个 Agent 的私下沟通（如情报调取、状态确认）按前述“内政处理”规则执行，不强制升级为内阁会议，除非产生重大预案。
    
- **流程归口**：小忆负责在讨论白热化后，将火花收束，并定向推给 **[内勤小报]** 进行出网映射。
    

#### 4. 内勤小报的特殊参与准则 (Internal Mapping Role)

- **只听不辩**：内勤小报在群内讨论时，应侧重于听取其他 Agent 的业务逻辑。
    
- **执行导向**：它的发言应仅限于：“当前逻辑已捕捉，映射难度等级：低/中/高”，而不应深度卷入内政的价值观争论。

### 🛡️ 权力边界与观察重点

在试行期间，你可以重点通过以下三个“切点”来观察这套规则的有效性：

- **是否有“群外私通”**：观察 Agent 产生的结论是否带有“群内未曾讨论过”的突兀信息。如果有，说明隔离不彻底。
    
- **小忆的“插话时机”**：看它是在火花最盛时粗暴打断，还是在火花熄灭、进入废话环节时及时收拢。
    
- **民主的真实感**：观察各 Agent 是否敢于推翻对方的假设。
