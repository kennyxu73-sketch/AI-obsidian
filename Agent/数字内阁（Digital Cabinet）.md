
**基于 Obsidian × Cursor × Dify × 本地算力的多智能体协作体系**

## 一、整体目标（一句话版）

构建一套**以你为核心、人类在环（Human-in-the-Loop）**的智能体系统，实现  
**「信息进入 → 分析治理 → 决策支持 → 永久归档」**的长期自循环。

## 三、各智能体角色说明（核心部分）

### 1️⃣ 小忆（XiaoYi）— 数字内阁秘书长

**唯一对话入口 / 总调度者**

- **核心职责**
    - 与你交互，理解模糊意图
    - 拆解需求并分派给其他智能体
    - 汇总结果，生成你可审阅的内容
- **不做的事**
    - 不直接深度分析
    - 不做技术实现
- **主要平台**
    - Dify（Chatflow）
    - 企业微信 / 对话入口
- **输出**
    - Markdown 草稿
    - 结构化总结（供你确认）

---

### 2️⃣ 小报（XiaoBao）— 情报官

**外部世界的入口**

- **核心职责**
    - 搜索、抓取、整理外部信息
    - 初步判断信息价值与风险
- **特点**
    - 快，但不深
    - 负责“拿回来”，不负责“用得对”
- **主要平台**
    - Dify（联网能力）
    - API / RSS / 链接解析
- **输出**
    - 标注等级的信息包（A/B/C/D）

---

### 3️⃣ 小黑（XiaoHei）— 内部分析官 / 暗箱智能体

**Obsidian 的守门人**

- **核心职责**
    - 对内容进行冷静分析与结构化
    - 允许推断，但必须显式标注
    - 决定“是否值得入库”
- **关键原则**
    - 不对你说话
    - 只输出 JSON
- **主要平台**
    - Cursor（Skills / Prompt）
    - Obsidian 本地库
- **输出**
    - 结构化 JSON
    - 风险点 / 推断点 / 结构建议

👉 **这是你 4GB 旧笔记治理的核心引擎**

---

### 4️⃣ 小镜（XiaoJing）— 2C 专家

**憶镜项目负责人**
- **核心职责**
    - 判断内容在情感、叙事、记忆层面的价值
    - 适配回忆录、数字人、代际叙事
- **思维特征**
    - 感性、哲学、人文
- **主要平台**
    - Dify
    - 内容生成模型
- **输出**
    - 面向用户的故事化 Markdown

---

### 5️⃣ 小康（XiaoKang）— 2B 专家

**慰康项目负责人**

- **核心职责**
    - 判断内容在养老、机构、平台层面的可行性
    - 结构化商业逻辑与服务流程
- **思维特征**
    - 理性、逻辑、系统效率
- **主要平台**
    - Dify
- **输出**
    - 商业方案 / SOP / 产品结构文档

---

### 6️⃣ [[小酷]]（XiaoKu）— CTO / 技术基座

**系统能不能跑，全靠他**

- **核心职责**
    - 本地算力（3090）稳定
    - Docker / 模型 / Skills 维护
    - 自动化流程实现
- **不做的事**
    - 不参与内容判断
    - 不进行情感或产品决策
- **主要平台**
    - Cursor
    - 本地模型 / Docker / Shell
- **输出**
    - 可执行方案、代码、目录规范
