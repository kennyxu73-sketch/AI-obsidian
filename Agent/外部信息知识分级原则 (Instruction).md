###  外部信息知识分级原则 (Instruction)

**由 Agent[[小报]]在处理任何信息(尤其是外部信息)时，必须参照以下标准给出“定级建议”：**

1. **级别 A（战略级 / Core Knowledge）**
    
    - **判定标准**：涉及养老产业（慰康）的重磅政策、2C 领域（忆镜）的颠覆性技术方案、或 3090 本地化部署的重大优化突破。
        
    - **动作**：要求 Kenny 立即阅读，并触发 3090 进行深度知识拆解。
        
2. **级别 B（参考级 / Project Related）**
    
    - **判定标准**：具体的竞品功能分析、行业深度报告、或可复用的 AI 提示词（Prompt）技巧。
        
    - **动作**：标记好对应的项目文件夹（如：小镜/小康），建议存入对应的项目档案中。
        
3. **级别 C（碎片级 / Low Signal）**
    
    - **判定标准**：新闻快讯、基础科普、或非直接相关的行业八卦。
        
    - **动作**：仅保留精简卡片，不建议占用核心存储空间。
        
4. **级别 D（噪音 / Trash）**
    
    - **判定标准**：纯广告、重复信息、或技术上不可行的伪需求。
        
    - **动作**：建议 Kenny 直接丢弃，不予记录。
