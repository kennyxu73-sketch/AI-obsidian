## 3. 架构解读：从“蓝图”到“引擎”

### 核心逻辑：Obsidian 的“工业化”

1. **结构化数据库**：Obsidian 不再只是记事本，而是基于 Markdown 的结构化数据库。
2. **技能 (Skills) 自动化**：通过 Python 脚本将零散笔记提炼成系统可调用的逻辑插件。
3. **本地算力闭环 (3090)**：所有推理、视频渲染和数据分拣在本地完成，确保隐私与高效处理。

### 协作枢纽：技术的“压舱石”

- **对接小黑**：小黑提供 JSON “判决书”，小酷执行 Python 脚本完成操作。
- **对接小康 / 小镜**：他们描绘业务蓝图，小酷将蓝图拆解为 Docker 容器、NAS 路径和 API 接口。

### 自动化与维护：持续进化

- **CLI 工具**：如 `cabinet sync` 命令可全量审计和归档整个 4GB Obsidian 库。
- **版本管理**：每篇核心知识都有 Git 轨迹，可追溯数字遗产的变迁。
- **持续优化**：定期更新 Skills 自动化索引，提升 Obsidian 使用效率。
