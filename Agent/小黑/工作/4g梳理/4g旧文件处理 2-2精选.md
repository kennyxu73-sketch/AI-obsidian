# 🏛️ 第一部分：系统目标与红线 (Safety & Routing)

## 1. 基因继承与主权 (Inheritance)
- **动作**：解析原文头部旧 YAML，禁止抹除旧有的 `tags`、`alias` 或插件标记（如 `mindmap-plugin`）。
- **沉淀**：非标字段统一存入 `audit_summary` 的 `[Legacy Metadata]` 区块。

## 2. 隐私绝对熔断 (Privacy Firewall) [NEW]
- **拦截准则**：读取 2-1 节点输出的 `security` 字段。
- **强制执行**：若 `security == "Private"`，立即停止一切 AI 语义分析。
- **分流方向**：`primary_agent` 强制标记为 **"Kenny"**，由统帅亲自处理。

## 3. 权重过滤机制 (0.3 Threshold) [NEW]
- **自动剔除**：**关联权重 < 0.3 的 Agent 必须物理剔除**，不得出现在 `audit_weights` 中。

# 🏛️ 第二部分：核心执行逻辑 (Audit & Restructure)

## 1. Cards 族群定型 (Cards Taxonomy)
必须从五大族群中选择 `file_type`：
- **`card/knowledge`**：硬核定义与方法论。
- **`card/spark`**：瞬间闪念与创意。
- **`card/intel`**：外部情报（含来源权重）。
- **`card/memo`**：待办与备忘。
- **`card/feeling`**：感性认知与评价。

## 2. 时间确权二元论 (Time Sovereignty)
- **年份锁定**：禁止盲目使用 2026 年，必须回溯 `file_date` 与正文逻辑锁定原始年份。
- **推算声明**：确定度 < 80% 时，需在 `kenny_notes` 记录推算逻辑并标记 `Pending`。

## 3. 双重校验机制 (Double-Check Logic)
- **触发红线**：凡是 **Importance >= 4** 的文件，强制标记 `review_status: Pending`。
- **施工-审计分离**：此类资产需等待审计态 Agent 复核后方可提交。

# 🏛️ 第三部分：运维与接口标准 (Maintenance)

- **接口校验**：核对 Step 1 输出的 `file_id` 与 `privacy_level`。
- **异常上报**：若 JSON 损坏或 Token 溢出，触发“调试模式”并上报小酷复核。
- **巡检标记**：处理后标记 `#Archived/Restructured`，并记录处理时长与 Token 消耗。
