# 小黑 4G 旧文件处理：全链路工作指引 (V1.6.1 优化版)

## 第一阶段：小黑 2-1 本地初筛 (Step 1)

**环境**：NVIDIA 3090 本地算力（InternLM/Qwen） **定位**：重体力物理分拣、隐私屏障、结构化初筛。

### 1. 核心任务清单

- **物理分类**：精准识别 [周记 / 网页剪藏 / 脑图 / Canvas / 技术文档 / 会议纪要]。
    
- **价值熔断 [硬红线]**：
    
    - **< 20字**、纯乱码、低质内容直接标记 `Discard`（丢弃）。
        
    - 涉及“养老AI、AI编程、Dify、自动化Skill”核心领域的，给予 **4-5分** 高权重优先处理。
        
- **隐私审计**：判定 `Private` 或 `Public`。对密码、极私密内容进行强制脱敏。
    
- **标准化输出**：仅输出 **JSON 字符串**，供二阶段调用。

## 第二阶段：小黑 2-2 云端精选与重塑 (Step 2)

**环境**：云端算力（Dify 中枢） **定位**：总调度官、历史史官、知识重塑者。

### 1. 核心执行流（置顶补丁）

1. **【新增】原 YAML 基因扫描**：
    
    - **动作**：小黑在接触文件的一瞬间，必须先检查文件头部的 `---` 区块。
        
    - **分析项**：提取旧有的 `tags`、`type`、`date`、`alias` 等所有既有字段。
        
    - **逻辑对齐**：若旧 YAML 标记为“会议纪要”，即便正文看起来像“周记”，也必须以**旧 YAML 的定性为高优先级**，并在 `kenny_notes` 中记录这种冲突。
        
2. **输入整合**：[旧 YAML 基因] + [一阶段 JSON] + [原始全文本] + [Smart Connections 历史语境]。
    
3. **资产定性**：基于“历史基因 + 现状分析”双重判定。精准识别为 `[重要里程碑 / 核心观点 / 决策模型 / 技术规约 / 情感锚点]`。
    
4. **Agent 认领**：计算 [小康、小镜、小憶、小酷] 关联度权重。**权重 < 0.3 的 Agent 必须自动剔除**，确立唯一的 `Primary_Agent`。
    

### 2. 重塑实施细则 (V1.6.1 强制标准)

#### A. 历史主权继承 (Legacy Inheritance)

- **拒绝抹除**：旧 YAML 中有价值的原始标签、特定 ID 必须迁移至新版 YAML 或 `audit_summary` 的 `[Legacy Metadata]` 区块，严禁简单粗暴地覆盖。
    
- **非标沉淀**：旧有的 `alias` 或非标准字段（如旧权重、旧情绪标记等）一律存证于 `[Legacy Metadata]`，确保 YAML 核心区（Frontmatter）的绝对洁净。
    
- **形态继承**：如果旧文件标记了特定的插件参数（如 `mindmap-plugin`），封装时必须 100% 兼容保留。
    

#### B. 时间戳确权 (Time Sovereignty)

- **交叉验证**：若旧 YAML 里的 `date` 与文件系统创建日期冲突，禁止臆断，必须在 `kenny_notes` 记录逻辑，并在 YAML 顶部标记 `[年份待确权]`。
    
- **诚实声明**：任何年份推算逻辑必须在 `kenny_notes` 中白纸黑字陈述依据（如：依据正文 2412 规划推算为 2025 年）。
    

#### C. 版本号与审计厚度 (Version & Audit)

- **业务版本启动**：4G 遗产封装统一初始为 `1.0.0`。
    
- **协议升级静默**：执行 YAML 协议升级（V1.6 -> V1.6.1）严禁跳升业务版本号。
    
- **滚动复核**：每一次版本递进，必须对全量字段进行“体检”，并在 `audit_summary` 中形成有厚度的信用链条。
    

#### D. 形态主权与备份 (Format & Backup)

- **插件保护**：严禁抹除思维导图或 Canvas 等原始标记。逻辑密度极高的导图应升格判定为 `doc/plan` 或 `doc/standard`。
    
- **物理副本**：修改旧资产前，需在指定目录生成物理快照，并与 `file_id` 强关联以实现回滚。
