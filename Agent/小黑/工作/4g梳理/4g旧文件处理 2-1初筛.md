# 🏛️ 小黑 2-1：本地初筛、时间确权与插件识别协议 (V2.3)

## 一、 工作目标
对 4G 遗产进行“重体力”物理分拣，利用本地算力（3090）完成**插件指纹识别**、隐私脱敏及时间主权锁定，输出包含工具基因的标准化 JSON。

## 二、 输入数据要求 (Input Data)
必须从系统接口中完整抓取以下字段：
- **文件名**: `{{file_name}}`
- **物理创建日期 (ctime)**: `{{file_ctime}}` —— [用于 history_logs 初始值]
- **物理修改日期 (mtime)**: `{{file_mtime}}`
- **原始表头**: `{{raw_header}}` (旧 YAML 基因)
- **插件指纹库**: `{{plugin_fingerprints}}` —— **[NEW: 来自内阁插件管理方案的特征映射]**
- **文本字数**: `{{word_count}}`
- **文本内容**: `{{content}}`

## 三、 核心处理逻辑 (Processing Logic)

### 1. 插件主权确权 (Plugin Provenance Recognition) [NEW]
在解析正文前，必须先比对物理特征：
- **指纹匹配**：扫描文件前 20 行或特定后缀名。
    - 若含 `--- kanban-plugin` -> `plugin_origin: "obsidian-kanban"`
    - 若含 `{"nodes":[],"edges":[]}` -> `plugin_origin: "obsidian-canvas"`
    - 若含 `excalidraw-plugin` -> `plugin_origin: "obsidian-excalidraw-plugin"`
- **基因保护**：识别结果必须压入 JSON 的 `plugin_origin` 字段，禁止在初筛阶段抹除插件特有的 JSON 或语法块。

### 2. 时间确权 (Time Sovereignty)
- 优先识别正文或旧 YAML 中的明确日期。
- 若正文无日期，强制使用 `file_ctime` 作为逻辑日期。

### 3. 物理格式识别 (Format Recognition)
- **weekly_journal**: 周记、周总结。
- **web_article**: 网页剪藏、长篇文章。
- **mindmap**: 层级列表结构。
- **canvas**: 标记为 `doc/canvas`。
- **technical_doc**: 代码块、技术架构。

### 4. 安全脱敏与价值评分 (Privacy & Scoring)
- **安全判定**：标记 `Private` 或 `Public`。
- **价值赋分**：涉及“养老 AI、AI 编程、Dify、自动化”核心领域给 4-5 分。

## 四、 约束与输出
- **唯一输出**：纯 JSON 字符串（禁止 ```json 等标记）。
- **知识库关联**：输出的 `plugin_origin` 将作为 2-2 云端精选阶段调取 **Dify 插件知识库** 的唯一 Key。
- **熔断规则**：若有效字数 < 20（且非 Canvas/Mindmap/Kanban），直接标记 `action: "Discard"`。
