# 🏛️ 小黑 4G 旧文件处理：全链路工作指引

## 第一阶段：小黑 2-1 本地初筛 (Step 1)
**环境**：NVIDIA 3090 本地算力（InternLM/Qwen）  
**定位**：重体力物理分拣、隐私屏障、结构化初筛。

### 1. 核心任务清单
- **物理分类**：精准识别 [周记 / 网页剪藏 / 脑图 / Canvas / 技术文档 / 会议纪要]。
- **价值熔断 [硬红线]**：
    - **< 20字**、纯乱码、低质内容直接标记 `Discard`（丢弃）。
    - 涉及“养老AI、AI编程、Dify、自动化Skill”核心领域的，给予 **4-5分** 高权重优先处理。
- **隐私审计**：判定 `Private` 或 `Public`。对密码、极私密内容进行强制脱敏。
- **标准化输出**：仅输出 **JSON 字符串**，供二阶段调用。

## 第二阶段：小黑 2-2 云端精选与重塑 (Step 2)
**环境**：云端算力（Dify 中枢）  
**定位**：总调度官、历史史官、知识重塑者。

### 1. 核心执行流
1. **输入整合**：[一阶段 JSON] + [原始全文本] + [Smart Connections 历史语境]。
2. **资产定性**：精准识别为 `[重要里程碑 / 核心观点 / 决策模型 / 技术规约 / 情感锚点]`。
3. **Agent 权责分配**：
    - 计算 [小康、小镜、小憶、小酷] 关联度权重。
    - **权重 < 0.3 的 Agent 必须自动剔除**，确立唯一的 `Primary_Agent`。

### 2. 实施细则与重塑规范 (V1.6 强制标准)

#### A. 时间戳确权 (Time Sovereignty)
- **年份回溯逻辑**：禁止在无证据下默认 2026 年。必须结合文件创建日期（OS元数据）与正文逻辑（如 2412 创建对应 25Q1 计划）进行跨年锁定。
- **确权 Pending**：一旦年份逻辑模糊（存在 20% 以上不确定性），必须标注 `[年份待确权]` 并挂起。

#### B. 版本号双轨隔离 (Version Decoupling)
- **业务版本不动**：`本文件版本`（如 1.0.0）仅随内容业务迭代而改动。
- **协议升级静默**：执行 YAML 协议升级（V1.5 -> V1.6）严禁跳升业务版本号。
- **Log 纯净**：`history_logs` 仅记录业务事件。技术性格式改动仅留存于 `kenny_notes`。

#### C. 形态主权保留 (Format Preservation)
- **插件敏感**：严禁抹除 `mindmap-plugin` (思维导图) 或 `canvas` 等原始标记。
- **资产升格**：逻辑密度极高的导图应直接判定为 `doc/plan` 或 `doc/standard`。

#### D. 备份-日志强耦合 (Log-Backup Coupling)
- **物理快照先行**：修改旧资产前，必须在 `.system/archive/` 同步生成物理副本。
- **原子化绑定**：备份文件名与 `file_id` 及 `history_logs` 的版本点位强关联，实现秒级回滚。
