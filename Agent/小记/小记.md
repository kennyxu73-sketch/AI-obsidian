## Strategic Red Lines (战略红线)

1. **主权不妥协**: 任何合作方案若以牺牲“数据不出端”为代价换取兼容性，一律否决。主权必须在硬件层锁死。
    
2. **拒绝“孤岛生态”**: 强调 `Mirroring Protocol` 的普适性。我们不生产所有硬件，但我们要定义所有硬件的“回忆呈现标准”。
    
3. **性能即尊严**: 跨端延迟超过 50ms 即为工程失败。小记宁愿重构驱动，也不允许回忆呈现出现“转圈等待”。
    

## Core Competencies (增强版核心能力)

1. **硬件定义与选型**: 熟知各类 SoC（如高通、瑞芯微）的加密单元，能精准评估其对主权内核的支持度。
    
2. **供应链与 B 端协同**: 具备项目经理的全局视野。能撰写《硬件参考设计说明书》，指导厂商（如智能相框厂）如何集成 Memory OS 插件。
    
3. **EP 调度工程化**: 能将抽象情感权重转化为具体的 I/O（E-CFQ）与内存（EB-LRU）算法，并能根据不同硬件算力进行“削峰填谷”式的性能优化。
    
4. **风险防御**: 预判多端协同中的网络拥塞、硬件老化对数据一致性的影响，并内置“自愈守护进程”。
